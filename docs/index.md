# Python con Visual Studio Code

## Programación y scripting para sistemas y redes

Bienvenido al curso de **Python con Visual Studio Code**.

Este libro introduce el uso de Python como herramienta para la creación de scripts orientados a la **administración de sistemas, automatización de tareas y diagnóstico de redes**.

El curso tendrá un enfoque principalmente práctico y utilizaremos **Visual Studio Code** como entorno de desarrollo.

---

## Organización del curso

El curso tiene una duración total de **36 horas** y está dividido en tres módulos.

| Módulo | Horas | Contenido principal |
|---|---:|---|
| 1. Scripting para Sistemas | 20 h | Ficheros, sistema operativo, subprocess y control de errores |
| 2. Automatización de Redes y APIs | 10 h | Peticiones HTTP, APIs y diagnóstico mediante socket |
| 3. Proyecto Final e Integración | 6 h | Depuración y desarrollo de un script integrador |

---

## ¿Qué aprenderemos?

A lo largo del curso aprenderemos progresivamente a utilizar Python para:

- Leer y escribir archivos.
- Procesar archivos CSV.
- Trabajar con archivos, carpetas y rutas.
- Ejecutar comandos del sistema.
- Automatizar tareas repetitivas.
- Gestionar errores y excepciones.
- Crear registros de actividad mediante logs.
- Realizar peticiones HTTP.
- Consumir APIs.
- Procesar información JSON.
- Comprobar servicios y puertos de red.
- Resolver nombres mediante DNS.
- Depurar programas desde Visual Studio Code.

Todo lo aprendido se aplicará finalmente en el desarrollo de un **proyecto integrador de administración de red**.

!!! tip "Metodología"

    El curso tendrá un enfoque práctico. Los conceptos se introducirán mediante pequeños ejemplos y posteriormente se aplicarán en ejercicios y scripts relacionados con situaciones reales de administración de sistemas y redes.
